## WP13: FP 系の ALU 命令（`mn_fp_alu*`）

正解は公式エミュレータ（契約 §1）。下の規則は、公式エミュレータで照合済みのベクタ（WP03 の unit `fpalu`、`--official-expect` 後の全 151,856 行）とすべて一致する。
Rust Sim（`viz/core/src/machine.rs` の `alu_lanes`、`float_*`、`float::block_float`）とは、入力の精度縮減（`r`）だけが違う。

### モジュール

| モジュール | 内容 |
| --- | --- |
| `mn_fp_alu` | PE 1 個分。rsqrt、relu0〜3、lrelud / lreluo / ilrelud、max / min（浮動小数点）、floor、ftoi（符号あり・なし）。passa と packbit も実行できる（振り分けでは `mn_alu_int` に行く）。入力の `r`（rounda / roundb） |
| `mn_fp_alu_lane` | `mn_fp_alu` の要素ごとの部分（形式 W / EB / M をパラメータで持つ。倍精度 1、単精度 2、半精度 4 個を並べる） |
| `mn_fp_alu_bfn` | MAB 1 個分のブロックフロート化（dbfn、fbfn、gbfn、hbfn/n、hbfe/n） |
| `mn_fp_alu_bflane` | `mn_fp_alu_bfn` の要素ごとの前処理 |
| `mn_alu_rnd`（WP11、`rtl/alu`） | `r` の単精度→半精度の丸め。整数 ALU と共有する |
| `mn_alu_cls`（WP11、`rtl/alu`） | 振り分け。`cls_fp` がこの 2 モジュールの担当で、`mn_fp_alu` の `cls_bf` がどちらかを決める |

### 形式とバス

- 倍精度 1/11/52（バイアス 1023）、単精度 1/8/23（127）、半精度 1/6/9（31）。指数 0 はゼロ、全 1 は無限大（仮数は問わない）。非正規化数と NaN はない（SDM 1.3）。
- ALU の入出力は 2 長語（128bit、bit 127 が 1 語目の MSB）。要素は MSB 側から詰まる。
- 要素ごとの命令は **MSB 側の長語の要素だけ**を計算する（倍精度 1、単精度 2、半精度 4 個）。結果の LSB 側の長語は x の LSB 側の長語（`r` を付けたときは 0）。
- マスクフラグは 4bit で、bit 3 が MSB 側の要素。倍精度の要素は 4 ビット、単精度は 2 ビットを同じ値にする。
- dmode 11（疑似単精度）は bfn でだけ意味を持つ。要素ごとの命令では単精度として扱う。

### 入力の精度縮減（`r`、rounda / roundb、SDM 3.6.12.19）

公式エミュレータの式（WP03 の `r_round`）。Sim の通常の丸めとは違う。

```
入力の単精度 4 語 w0..w3（バスの bit 127:96 から順）→ 半精度 4 個を MSB 側の長語へ。LSB 側の長語は 0。
E = 単精度の指数欄、m = 仮数 23bit
m9 = RNE(m >> 14)   （保持 9bit、丸めビット m[13]、スティッキー m[12:0]、偶数丸め）
c  = m9 の桁上がり（m9 = 0x200 のとき 1）
h  = 符号 | clamp(E - 96 + c, 0, 63) << 9 | (m9 & 0x1ff)
```

- 0 への切り捨てをしない。-0 は 0x8000、下にあふれた値は指数 0 のまま丸めた仮数が残る。∞ と上にあふれた値は指数 63 で仮数が残る。
- エミュレータは半語（dmode 10）以外の `r` を実行時エラーにする。`mn_alu_cls` がそれを `cls_bad`（E_UNSUPPORTED）にするので、このユニットには来ない（来れば dmode を見ずに丸める）。
- 実装は WP11 の `mn_alu_rnd`（整数 ALU と同じモジュール）。

### 要素ごとの命令（x の要素 a、y の要素 b、幅 W）

| 命令（aluop） | 結果 | フラグの条件 |
| --- | --- | --- |
| passa（01010） | a（バス全体が x） | a == 0（ビット列として。-0 は 0 ではない） |
| packbit（10011） | (a << 1) \| b の MSB | b の MSB == 0 |
| relu0〜3（10100〜10111、k = aluop[1:0]） | a の bit (W-1-k) が 0 なら b、1 なら -0（符号ビットだけ） | その bit == 0 |
| lrelud / lreluo / ilrelud（11000〜11010） | a ≥ 0（符号 0）なら b。負なら b の指数を -1 / -3 / +1 する。b が ∞ ならそのまま。下にあふれる（指数 ≤ 1 / ≤ 3）と -0（b の符号によらない）。ilrelud は指数 emax-1 から ∞（仮数は残る）、ゼロから最小の正規化数（仮数は残る）になる | a の符号 == 0 |
| max / min（11011 / 11100） | 下の比較で a を選べば a、そうでなければ b | a を選んだか |
| floor（11110、iselb 110） | 下の規則 | 常に 0 |
| ftoi（11110、iselb 111、is_unsigned） | 下の規則 | 常に 0 |
| rsqrt（10000） | 下の近似 | a の符号 == 0 |

**max / min**: 符号と大きさの鍵 key(v) = (符号 ? -1 : 1) × (指数と仮数の欄をつないだ整数)、ただし指数が 0 なら key = 0。max は key(a) ≥ key(b)、min は key(a) ≤ key(b) のとき a。
等しいとき（±0 どうし、指数 0 どうしを含む）は a。∞ どうしは仮数の大小で比べる。

**floor**（E = 指数欄 − バイアス）:
- 指数 0、指数全 1、E ≥ M（整数）: a のまま。
- E < 0（0 < |a| < 1）: 正なら +0（0）、負なら -1.0。
- 0 ≤ E < M: 小数部の下位 M−E ビットを 0 にする。負で小数部が 0 でなければ、さらに 2^(M−E) を指数・仮数の欄に足す（繰り上がりで指数が 1 増えることがある）。

**ftoi**（0 方向への切り捨て。整数の幅は要素の幅 W）:
- 大きさ mag = (1.仮数) × 2^E の整数部。E < 0（ゼロを含む）なら 0。
- 符号あり: E ≥ W−1（∞ を含む）なら飽和（正 0x7f..f、負 0x80..0）。そうでなければ負は −mag。
- 符号なし: **符号を無視する**。E ≥ W（∞ を含む）なら全 1、そうでなければ mag（負の数も大きさを返す）。

**rsqrt**（近似逆数平方根。SDM 3.6.12.9 は「約 5bit」とだけ書く。規則は公式エミュレータから抽出したもので Sim の `float_rsqrt` と同じ。照合で全行一致）:

```
e     = a の指数欄（符号は無視。ゼロと ∞ も特別扱いしない）
t     = a の仮数の上位 4bit
out_e = BIAS + (BIAS + 1) / 2 − 1 − ceil(e / 2)      （倍精度 1534、単精度 190、半精度 46 から引く）
out_m = MANT5[e & 1][t]  を仮数の上位 5bit に置き、残りは 0
結果  = 0 | out_e | out_m          （符号 0）

MANT5[0]（e が偶数）= 13 11 10  9  8  7  6  5  4  4  3  2  2  1  1  0
MANT5[1]（e が奇数）= 31 30 28 26 25 23 22 21 20 19 18 17 16 15 14 13
```

### ブロックフロート化（bfn / bfe、SDM 3.6.12.12、4.4）

MAB の 4 PE の同じサイクルの入力から、次のブロックを作る（公式エミュレータと Sim の `compute_bfn` で同じ）。

| 命令 | dmode | ブロック | 残す仮数（keep） |
| --- | --- | --- | --- |
| dbfn | 00 | 各 PE の MSB 側の長語（倍精度 4 個） | 52 |
| fbfn | 01 | 各 PE の MSB 側の長語の 1 語目（4 個）と 2 語目（4 個）の 2 ブロック | 23 |
| gbfn | 11 | 各 PE の MSB 側の長語の 2 語（8 個） | 18 |
| hbfn/n、hbfe/n | 10 | 各 PE の MSB 側の長語の半語（16 個）と LSB 側の長語の半語（16 個）の 2 ブロック。iselb = 9 − n | n |

dbfn / fbfn / gbfn の結果の LSB 側の長語は 0。フラグは常に 0。aluop は bfn が 11110、bfe（拡張表現、半精度だけ）が 11101。

ブロックごとに（dr = M − keep、半精度は 9 − n、疑似単精度は 5）:

```
max_e  = ブロックの指数欄の最大
common = max_e + (指数が max_e の要素に「仮数の上位 keep bit が全 1」のものがあれば 1) + (半精度なら dr)
要素ごと（s = 符号、e = 指数欄）:
  common ≥ emax              → s | ∞（仮数 0）
  max_e == 0                 → s
  e == 0                     → bfe ? s : s | common
  d     = common − e
  flag  = bfe && (d > 6 + dr || (d == 6 + dr && 上位 keep bit が全 1 でない))
  shift = (flag ? d − 6 : d) + 1 + (半精度でなければ dr)
  r     = RNE((1.仮数) >> shift)     （疑似単精度は r << 5 を仮数とする）
  r == 0                     → bfe ? s : s | common
  それ以外                   → s | (flag ? 0 : common) | r
```

`r`（rounda、半精度だけ）は、各 PE のバスを上の式で丸めてから変換する（LSB 側の長語は 0 になるので、2 つ目のブロックは全部ゼロ）。

### インタフェースとレイテンシ

- `mn_fp_alu`: `mn_alu_int`（WP11）と同じ形。ALUC の欄 `pe_aluc_dmode`、`_aluop`、`_is_unsigned`、`_rounda`、`_roundb`、`_isela` に `pe_aluc_iselb` を加え（floor / ftoi / bfn の区別に使う）、`imm32` はない。`x`、`y`（128bit、丸める前の値）→ `z`（128bit）、`flags`（4bit）、`out_err`（このユニットが実行しない ALUC。z = 0、flags = 0）。`cls_bf`（組み合わせ回路、in_valid と無関係）は ALUC が bfn / bfe（`mn_fp_alu_bfn` へ送る）かどうか: aluop 11101、または 11110 で iselb が 11x でないもの。valid / ready、毎クロック 1 本。サイクル t に受け付けた要求の結果はサイクル t + 5 に出る。出力が受け取られないと全段が止まる。パラメータ `RND = 0` で入力の丸めとその段を外せる（呼び出し側で丸める場合。レイテンシは 4）。
- `mn_fp_alu_bfn`: ALUC は `pe_aluc_dmode`、`_aluop`、`_rounda`、`_iselb`。`x[128*p +: 128]` が PE p の入力、`z[128*p +: 128]` が結果、`flags[4*p +: 4]` は 0、`out_err` は bfn / bfe でない ALUC を受け付けたとき 1。valid / ready で 1 件ずつ。サイクル t に受け付けた要求の結果はサイクル t + 15 に出る（`r` 付きは t + 19）。
- 振り分け: `mn_alu_cls` の `cls_fp` のうち、`cls_bf` = 1 なら `mn_fp_alu_bfn`、0 なら `mn_fp_alu`。zero（aluop 11101、is_unsigned = 1、isela = 0101）は `mn_alu_cls` が `cls_int` にする。

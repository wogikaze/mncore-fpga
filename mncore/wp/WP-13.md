# WP13 FP 系の ALU 命令

- 依存: WP03
- 担当: `mncore/rtl/fpu/mn_fp_alu*`、`mncore/sim/tb/fpalu/`
- 参照: SDM 3.6.12.9〜14、3.6.12.18、3.6.12.19、Scrapbox「多重化される ALU 命令」「BFP パラメータの符号化」

## 作業

1. `mn_fp_alu` を作る。
   - 対象: dmax/dmin（FP）、relu 系（relu0〜3、lrelud/lreluo/ilrelud）、floor、ftoi、rsqrt（近似。表とアルゴリズムは Rust に合わせる）、packbit（FP 側）、bfn/bfe（ブロックフロート化。hbfn/n と hbfe/n）。
   - 入力の精度縮減（rounda/roundb: 単精度 → 半精度）も扱う。
2. インタフェースは WP11 の `mn_alu_int` と同じにする。上位で選ぶ。
3. ベクタで全件一致させる。

## 受入基準

- 全ベクタが一致する。rsqrt は近似の規則を `rtl/fpu/SPEC.md` に追記する（WP12 と共有するファイル。自分の節だけを書く）。

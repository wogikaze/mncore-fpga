# WP11 整数 ALU

- 依存: WP03（ベクタ）。ベクタができるまでは `vectors_fixed` で進めてよい。
- 担当: `mncore/rtl/alu/`、`mncore/sim/tb/alu*/`
- 参照: SDM 3.6.12、Scrapbox の ALUC 表、`viz/core/src/machine.rs` の ALU 部

## 作業

1. `mn_alu_int`: aluop の整数・ビット演算を実装する。
   - 対象: add、sub、inc、dec、not、and、or、xor、max/min（整数）、passa、lsl/lsr/bsl/bsr、lnot、packbit、imm/immu、zero。
   - 精度 l/i/s（dmode 00/01/10）を SIMD レーンとして扱う。
   - unsigned を扱う。
   - マスクフラグ（omr に書く値。SDM 3.6.12.1）を出力する。
2. 入力は 2 長語分（cycle ごとに 128bit）。1 サイクルで処理しても複数サイクルで処理してもよい。valid/ready のインタフェースにする。
3. msl/msr は PE をまたぐので**ここでは実装しない**（WP30）。
   FP 系の aluop は `mn_alu_fp`（WP13）に回す。そのための振り分け用の出力を用意する。
4. ベクタテストで全件一致させる。

## 受入基準

- ALU 整数の全ベクタが一致する。lint と synth を通し、LUT 数を報告する。

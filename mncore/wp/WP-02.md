# WP02 ゴールデン基盤（正解生成と比較）

- 依存: WP00
- 担当: `mncore/tools/golden/`
- 参照:
  - `third_party/mncore/docs/simulator-throughput.md`
  - `viz/core/scripts/check-conformance.sh`
  - SDM 3.4.3（d get）、3.4.4（d set）

## 目的

1 つの `.vsm` から、公式の結果、Rust Sim の結果、比較対象（RTL / FPGA）の結果を正規化ダンプ（`.ndmp`、契約 §4）で並べ、差分を出せるようにする。

## 作業

1. `golden/run_official.py <vsm>`: WSL 経由で `assemble3`（flat、パック前）と `gpfn3_package_main` を実行する。
   - `.asm` と公式の `.dmp` を出す。
   - `--offchip-memory-init zero` を既定にする。
2. `golden/norm_gpfn3.py`: 公式 dmp → ndmp。`d get` のすべての空間（LM0/LM1/GRF0/GRF1/T/L1BM/L2BM/PDM/DRAM など）に対応する。
3. `golden/run_rust.py <vsm>`: `third_party/mncore/viz/core` をビルドし（Windows の cargo でも WSL でもよい）、同じ `d get` の内容を ndmp で出す。
   - 必要なら Rust 側に小さな bin を追加する。追加するのは `mncore/golden_rs/` に置く別 crate で、viz/core は path 依存で参照する。**submodule は変更しない。**
4. `golden/ndiff.py a.ndmp b.ndmp [--only-pes n0c0b0m0p0,...] [--spaces LM0,LM1]`: 不一致の行を表示し、終了コードで結果を返す。
5. `golden/corpus.py`: コーパスの全 `.vsm` を分類した一覧 `golden/corpus.tsv` を作る。分類項目は次のとおり。
   - 使っている命令グループ（ALU 整数 / FP / MAU / 行列 / L1BM / L2BM / MV）
   - PE をまたぐ通信の有無
   - LM の最大アドレス
   - `d get` の有無
   - 「1 PE モードで比較できるか」
   - 後の WP はこの一覧を見てテストの対象を選ぶ。
6. 公式と Rust で、コーパスの全件の ndmp が一致することを確認する（既存の保証の再確認）。

## 受入基準

- `python mncore/tools/golden/run_official.py X.vsm` と `run_rust.py X.vsm` の ndmp が、コーパスの全件で `ndiff` 一致する。不一致があれば一覧にする。
- `corpus.tsv` ができていて、「1 PE で比較できる」件数を報告している。

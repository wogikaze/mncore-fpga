# WP21 1 PE 構成を実機で動かす（M1）

- 依存: WP20、WP04
- 担当: `mncore/rtl/top/`、`mncore/fpga/top_1pe/`
- 実機: **使う**

## 作業

1. `brd_host_if`、`mn_core`、命令メモリ、PE の記憶をつないだトップを作る。27MHz または PLL のクロックで動かす。
2. 配置配線する。タイミングが合わなければクロックを下げてよい。
3. `mnhost.py run X.asm` で、公式の hello_world と Welcome 問題を実行し、ndmp で一致させる。
4. 回帰のうち 20 本を実機で回す。

## 受入基準

- 実機で一致したことを、ログ付きで報告する。資源の使用率と動作周波数も載せる。

# WP36 行列（行列レジスタ、mwrite/mread、mfma/mmul）

- 依存: WP30（1 MAB の 4 PE 時分割。main にマージ済み）
- 担当: `mncore/rtl/mab/` の行列の部分（新しいファイル。例: `mn_mab_mat*.v`）、`mncore/sim/tb/mat/`
  - WP30 の `mn_mab.v`、`mn_pe_core.v` への組み込みに必要な最小限の変更も行ってよい。
- 参照:
  - SDM の行列レジスタと行列 MAU の章、`j_flat.yaml` の MAUC 欄（readh、mdw_side、ma などは `UNKNOWN.md`）
  - `mncore/status/WP-30.md` の WP36 への申し送り
  - `mncore/rtl/fpu/SPEC.md`（FMA の規則）
  - `viz/core` の行列の実装

## 作業

1. 行列レジスタ（MAB ごと）と `?mwrite` / `mread`、行列 MAU（mfma / mmul）を実装する。
   - `?mwrite` は bfn と同じように、検査だけのパスで 4 PE の入力を集めてから書く。
   - `mread` / `mfma` の結果は、通常のパスで PE ごとに渡す。
   - `$mreadf` は {PE, サイクル} で持つ。nop / noforward 以外の全ステップで更新する（契約 §1）。
   - `u_mat` / `mau_mw` の E_UNSUPPORTED を外す。
2. 面積が大きくなるので、行列 MAU は WP12 の `mn_fp_fma` を逐次に使い回す形を第一候補にする。
   - パラメータ `MAT`（0 = なし）で外せるようにする。
3. readh / mdw_side / ma の意味を公式エミュレータで確かめ、`UNKNOWN.md` への反映案を報告する。
4. 回帰 `sim/regress/run.py --pes 4` で、行列を使うコーパスが一致すること。
   - 除外していた 124 本が対象。L1BM / L2BM / MV を使うものは除く。

## 受入基準

- 行列を使い、1 MAB で比較できるコーパスが、RTL シミュレーションで公式と全件一致する。
- WP30 の 4 PE 回帰（260/260）と 1 PE 回帰（259/260）が退行しない。
- 合格条件の 3 つ（iverilog、lint、synth）を通す。資源を報告する。
- 実機で行列入りの機能別のビットストリームを作り、回帰の一部を確かめる。

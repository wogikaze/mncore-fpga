# WP31 L1BM ユニット

- 依存: WP21（M1）
- 担当: `mncore/rtl/l1bm/`、`mncore/sim/tb/l1bm/`
- 参照: SDM の L1BM の章（l1bmp/l1bmm/l1bmm4/l1bmd、RRN 縮約）、Scrapbox の L1BM 表、`mncore/spec/isa/j_flat.yaml` の l1bm_* 欄と `UNKNOWN.md`、WP03 の unit `rrn` のベクタ、`viz/core` の L1BM 実装

## 作業

1. L1BM（`L1BM_DEPTH` = 1024 長語。契約 §3、BSRAM は 4 ブロック）と、PE ⇔ L1BM の転送を単体のユニットとして作る。
   - 対象の命令: l1bmp、l1bmm、l1bmm4、l1bmd。
   - 分配と結合、RRN 縮約、フォワーディングレジスタ `lbf`、`$lbi`。
   - `l1bm_me` に頼らない（`UNKNOWN.md`）。
2. 境界のポートを `rtl/l1bm/README.md` に定義する。
   - 入力: デコーダの欄、PE 番号、PE 側の読み出しデータ。
   - 出力: PE への書き込みデータとマスク。
   - 前提: 縮小トポロジは 1 L1B、1 MAB（4 PE）。将来の 16 MAB も見込む。
   - 存在しない MAB の扱いは契約 §3（転送は捨てる、入力はゼロ）。
   - `mn_core` への組み込みは WP37 が行う。
3. 正解:
   - 縮約は WP03 の `rrn` ベクタ（全件公式一致）。
   - 命令列の単位では、公式エミュレータ（4096 PE を実行し、範囲を切り出す）と、縮小トポロジの Rust Sim（`sim_run --topology`）を使う。
   - L1BM 系のコーパスから比較できるものを選んで、テストを組む。

## 受入基準

- `rrn` ベクタが全件一致する。
- L1BM を使う命令列のテスト（公式を期待値にしたもの 30 本以上）が、ユニットのテストベンチで全件一致する。
- 合格条件 3 つ（iverilog、lint、synth）を通し、`-nowidelut` での資源を報告する。

## 作業

1. `mn_core` に L1BM（`mn_l1bm`、N_MAB=1、RRN=2）、L2BM（`mn_l2bm`、N_L1B=1、RRN=2、DAR=0）、MV（`mn_mv` + `sdr_bus64`）を組み込む。
   - 1 語の順序、`skip`、`busy`、`wait` の連携は各報告の申し送りに従う。
   - ホストの空間 6〜9 の調停もここで行う。
2. `mn_mab_mem` のコンテキストストアを、WP35 の `mn_pe_lsu #(.NPE(4))` に置き換える。
   - `subpe` が PE ごとの状態の番号を兼ねる。
   - 面積と速度が改善することを確かめる。
3. デコーダの判定の誤りを直す（`yaml` を直して `gen_dec.py` で生成し直す）。
   - `unsup_vec[83]` / `[88]`（WP32）。
   - `mv_unsup_vec`（WP33）。
4. 複製規則 `REPLICA`（WP-3x）を L1BM と L2BM の縮約・結合に入れる（パラメータ。既定 0）。
5. 回帰:
   - (a) 1 PE と 4 PE の既存の回帰が退行しないこと。
   - (b) L1BM / L2BM / MV を使うコーパスのうち、データの移動が実装したユニットの中で閉じるものが公式と一致すること。
   - (c) それ以外のものが、縮小トポロジの Rust Sim（ゼロ規則）と一致すること。既知の食い違いの命令は除く。
   - (d) `REPLICA=1` で、hello_world とほかの SPMD 的なプログラムが 4096 PE の公式と一致するかどうか。
6. 実機:
   - `fpga/top_m2/` に機能別のビットストリームを作る。L1BM + L2BM + MV + 整数 ALU + MAU が最低限。FP ALU と行列は入れられる範囲で。
   - hello_world を実機で実行し、DRAM に "Hello, world!" が出ることと、正解との一致を確かめる。
   - 回帰の一部（30 本以上）も実機で回す。

## 受入基準（M2）

- hello_world が実機で正解と一致する。
  - ゼロ規則では縮小トポロジの Rust Sim と一致すること。
  - 複製規則で公式と一致すれば、それも報告する。
- 回帰 (a)〜(c) を表で報告する。不一致は理由ごとに分類する。
- 資源（LUT4 75% 以下、BSRAM）と動作周波数を報告する。

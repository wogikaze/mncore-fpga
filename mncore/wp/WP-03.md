# WP03 ユニットテスト用ベクタの生成（vecgen）

- 依存: WP00
- 担当: `mncore/vecgen/`（Rust crate）、`mncore/sim/vectors_fixed/`
- 参照: `third_party/mncore/viz/core/src/float.rs`、`machine.rs`（ALU / MAU の評価部）、`blockop.rs`、`rrn.rs`

## 目的

RTL のユニット（整数 ALU、FP 演算、変換、縮約）を単体で検証するため、Rust Sim の**実装そのもの**を呼び出して期待値を作る（契約 §5 の `.vec` 形式）。

## 作業

1. `vecgen` crate を作り、`third_party/mncore/viz/core` を path 依存で参照する。
   - 公開されていない関数が必要なら、viz/core の該当ロジックを crate 内にコピーせず、まず報告で要望する。
   - 例外として、Sim に 1 命令だけの VSM を流して結果を取り出す「ブラックボックス方式」は許す。遅くてもよい。
2. 次の生成器を作る。
   - **ALU 整数**: aluop 全種 × dmode（l/i/s）× unsigned × 入力境界値（0、1、-1、最大、最小、ランダム）
   - **ALU FP 系**: max/min、relu 群、floor、ftoi、rsqrt、packbit、bfn/bfe（d/f/h、rounda/roundb）
   - **MAU ベクトル**: fma/mul/add/passa × D/F/G/H × round_out × sign / ext × zeroc
   - **FP の基本関数**: add / mul / fma の単体（WP12 用）。特殊値として ±0、±∞、最大と最小の正規化数、アンダーフロー境界、丸めの境界を入れる。
   - **RRN 縮約**: L1BM / L2BM の縮約の加算・最大・最小（WP31/32 用。後回しでよい）
3. `cargo run --release -- <unit> --n <count> --seed <s>` で `mncore/sim/vectors/<unit>/*.vec` に出力する。
4. 各 unit から 50 行ずつのサンプルを `sim/vectors_fixed/` にコミットする。
5. 各ベクタで「1 命令の VSM を公式エミュレータで実行した結果」と照合するモードを付ける（`--check-official`、各 unit から抜粋で 200 件）。

## 受入基準

- 上の各 unit で生成でき、`--check-official` の抜粋が全件一致する。
- `.vec` の列の定義を `vecgen/FORMAT.md` に書いてある。

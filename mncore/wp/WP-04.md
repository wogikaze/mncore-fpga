# WP04 ボード基盤: クロック、UART、ホストプロトコル、ホストツール

- 依存: WP00
- 担当: `mncore/rtl/board/`、`mncore/tools/host/`、`mncore/fpga/board_test/`、`mncore/sim/tb/board*/`
- 参照: `init/`（既存の LED サンプル、`build.bat`、`tangnano20k.cst`）、`docs/tools.md`
- 実機: **使う**（ボードロック必須）

## 作業

1. `brd_uart_rx` / `brd_uart_tx` を作る。パラメータでボーレートを変えられるようにし、FIFO を付ける。
   ピン割り当ては公式の Tang Nano 20K 資料で確認する（BL616 の UART に接続されたピン）。
2. `brd_host_if` を作る: フレームの受信、CRC8 の検査、コマンドの分配、応答の送信（契約 §7）。
   - コア側とのインタフェースは「メモリ書き込みポート」「メモリ読み出しポート」「RUN 制御 / ステータス」に分ける。
   - 仕様は `rtl/board/PROTOCOL.md` に確定させる。
3. `fpga/board_test/`: `brd_host_if` と BSRAM のテストメモリ（契約 §6 のメモリバス）をつないだデザイン。ビルド用の `build.ps1` も用意する。
4. `tools/host/mnhost.py` を作る。
   - `ping`、`write`、`read`、`run`、`status` のサブコマンド。
   - `.asm` の実行: `j`/`m` 語を命令メモリに積み、`d set` / `d get` をメモリの読み書きと `RUN` の分割に変換する。結果は ndmp で出力する。
   - pyserial を使う。COM ポートは自動で検出し、指定もできるようにする。
5. 実機で次を確認する。
   - ping
   - 64KB の書き込みと読み出しの一致
   - 通信速度（1 Mbps、2 Mbps、3 Mbps でエラーが出ないか）

## 受入基準

- RTL シミュレーション: プロトコルのテストベンチが PASS（CRC エラーの扱いも含む）。
- 実機: 上の 3 項目を確認した。実際の速度と、使えた最大のボーレートを報告する。
- 実機が使えないときは、シミュレーションまでで「実機は保留」と報告する。

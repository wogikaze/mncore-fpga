# WP32 L2BM ユニット

- 依存: WP31（L1BM、main にマージ済み）
- 担当: `mncore/rtl/l2bm/`、`mncore/sim/tb/l2bm/`
- 参照:
  - SDM の L2BM の章（Bcast/Bcast2/Distrib/Gather/FromL1b/Reduce/Reduce2/Imcast、DAR/DARBUF）
  - `j_flat.yaml` の l2bm_* 欄と、gwrite / gadr などの L1BM 側の欄
  - `UNKNOWN.md`（`l2bm_opcode` の 1100 など）
  - `mncore/rtl/l1bm/README.md`（ポート B、`mn_l1bm_rrn`）
  - `viz/core` の L2BM の実装

## 作業

1. L2BM（`L2BM_DEPTH` = 2048 長語、BSRAM 8 ブロック）と、L1BM ⇔ L2BM の転送を単体のユニットとして作る。
   - L1BM の中身へは、WP31 の `mn_l1bm` のポート B を通してアクセスする。
   - 縮約には `mn_l1bm_rrn` を流用する（l2bmr は `nin_m1=7`、l2bmr2 は `nin_m1=1`）。
2. DAR/DARBUF と、`l2bm_opcode` の意味を公式エミュレータで確かめる。
   - 未確定の欄（1100 など）も、プローブで決めて `UNKNOWN.md` に反映する案を報告する。
3. 境界のポートを `rtl/l2bm/README.md` に定義する。前提は縮小トポロジの 1 L2B・1 L1B。
   - 存在しない L1B への転送は捨てる。
   - 存在しない L1B からの入力はゼロとする。ただし l2bmr の集合の外は単位元（契約 §3）。
4. `mn_core` への組み込みは WP37 が行う。

## 受入基準

- L2BM を使う命令列のテスト（公式を期待値にしたもの 30 本以上）が、ユニットのテストベンチ（`mn_l1bm` を含む）で全件一致する。
- 合格条件の 3 つ（iverilog、lint、synth -nowidelut）を通し、資源を報告する。

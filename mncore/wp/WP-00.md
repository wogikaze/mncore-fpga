# WP00 キックオフ（lead が直接作業する）

- 依存: なし（ユーザーの了承が前提）
- 担当: リポジトリ全体の雛形

## 作業

1. nano20k で `git init` する。`.gitignore` に以下を入れる。
   - `.venv/`
   - `init/*.json`、`init/*.fs`
   - `mncore/sim/vectors/`
   - `**/build/`
   - `*.vcd`、`*.fst`
   - `mncore/.board.lock`
2. `third_party/mncore` に wogikaze/mncore を submodule として追加し、現在のコミットに固定する。
3. ディレクトリの雛形を作る（契約 §8 のとおり）。空のディレクトリには `.gitkeep` を置く。
4. `mncore/tools/simrun.py` を作る。
   - `mncore/sim/tb/<unit>/files.txt` を読み、iverilog でビルドして実行する。
   - 最後の行が `PASS` なら終了コード 0、それ以外は 1 を返す。
   - `--lint` を付けると verilator の lint も実行する。
   - `--synth` を付けると yosys の synth_gowin を実行する。
   - サンプル unit `selftest`（カウンタとそのテストベンチ）を同梱する。
5. `mncore/requirements.txt` を作る（pyyaml、pyserial）。venv にインストールする。
6. `mncore/status/BOARD.md` を作り、全 WP を「未着手」で並べる。
7. 公開リポジトリを作成し、remote を設定する。ユーザーの了承を得てから行う。

## 受入基準

- `python mncore/tools/simrun.py selftest --lint --synth` が PASS する。
- 初回コミットが済んでいる。

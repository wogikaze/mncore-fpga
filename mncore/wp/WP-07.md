# WP07 デバイス資源の確認とインファレンスのレシピ

- 依存: WP00
- 担当: `mncore/fpga/recipes/`、`mncore/07-device-budget.md`（新規）

## 目的

GW2AR-LV18 の資源と、yosys / nextpnr-himbaechel が実際にどう推論するかを確かめ、契約 §6 の資源予算を確定させる。

## 作業

1. 公式の資料で確認する: LUT、FF、BSRAM（ブロック数、構成できる幅と深さ）、SSRAM、DSP（乗算器の種類と個数）、PLL、内蔵 SDRAM。
2. 小さなデザインで推論の結果を確かめる。
   - 64bit 幅 × 256 / 512 / 2048 深さの 1R1W と 2R1W RAM が何ブロックになるか。
   - `byte enable` 付きで書けるか。
   - 18×18、27×18、53×53 の乗算が、DSP 何個と何 LUT になるか。
   - パイプライン段数ごとの Fmax（nextpnr の報告値）。
3. 推論が素直にいくコードのテンプレートを `fpga/recipes/*.v` に置く。
   - 例: `mn_ram_1r1w.v`、`mn_mul_pipe.v`
4. 資源予算の確定案を `07-device-budget.md` に書く。lead が契約に反映する。

## 受入基準

- 各テンプレートが合成と配置配線を通り、資源と Fmax の表がある。

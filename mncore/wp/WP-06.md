# WP06 Rust Sim の縮小トポロジ対応

- 依存: WP00（ユーザーの了承: wogikaze/mncore にブランチを作ること）
- 担当: `third_party/mncore` の新しいブランチ `topo-param`（submodule 内）。nano20k 側は submodule の参照の更新だけ。
- 参照: `viz/core/src/machine.rs`、`blocks.rs`、`mv.rs`、`trace.rs`

## 目的

FPGA の縮小構成（契約 §3）と同じ構成で Rust Sim を動かし、PE をまたぐ通信を含む命令列の正解を作れるようにする。

## 作業

1. チップ構成の定数（L2B=8、L1B=8、MAB=16、PE=4、各メモリの容量）を、実行時のパラメータ `Topology` にまとめる。
   既定値は実チップにし、既存の挙動とテストを変えない。
2. 縮小構成での意味は次のとおり。
   - 存在しない L2B / L1B への分配は捨てる。
   - 存在しない L2B / L1B からの結合や縮約はゼロとして扱う。
   - 容量の外へのアクセスはエラーにする。
   - この意味の定義を `docs/topology.md` に書き、FPGA 側（契約 §3）と一致させる。
3. CLI に `--topology l2b=1,l1b=1,mab=16,lm=256,...` を追加する。
4. 既定構成で、既存の全テスト（`cargo test --release`、`check-conformance.sh`）が通ることを確認する。

## 受入基準

- 既定構成で回帰なし。
- 縮小構成の例を 3 つ以上用意し、PE ローカルな命令列について「縮小構成の結果 = 全構成の結果を該当範囲で切り出したもの」が一致する。

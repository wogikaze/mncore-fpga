# WP05 内蔵 SDRAM コントローラ

- 依存: WP00
- 担当: `mncore/rtl/sdram/`、`mncore/fpga/sdram_test/`、`mncore/sim/tb/sdram/`
- 実機: **使う**（ボードロック必須）

## 目的

GW2AR-18 に内蔵された 64Mbit SDR SDRAM を、契約 §6 のメモリバス（64bit の長語単位）で使えるようにする。

## 作業

1. 既存の OSS 実装を調べ、ライセンスが合うものを流用するか参考にする。
   - 候補: Tang Nano 20K 向けに公開されている SDRAM コントローラ（nand2mario 氏などの実装）。
   - 出典とライセンスを `rtl/sdram/README.md` に書く。
2. `sdr_ctrl`（SDRAM 側、32bit）と `sdr_bus64`（64bit の長語バスへの変換と、要求のキュー）を作る。クロックは 27MHz から PLL で作る。
3. シミュレーション用の SDRAM モデル（簡易でよい）とテストベンチを作る。
4. `fpga/sdram_test`: 全域をパターンで書いて読み、照合する。結果は LED で示す。WP04 が先に終わっていれば UART で報告する。
5. 帯域を測る（連続読み出しと、ランダムな 64bit 読み出し）。

## 受入基準

- シミュレーションが PASS。実機で 8MiB 全域の照合が通り、実測の帯域を報告している。
